# Music Speed

Prosty odtwarzacz: wczytaj katalog z muzyką (także podkatalogi), nawigacja ⏮ −10s ⏯ +10s ⏭,
przyspieszanie lub zwalnianie ×1.1 / 1.2 / 1.3 / 1.4 / 1.5 / 1.6 / 2.0 / 3.0 (wysokość dźwięku zachowana).

Budowanie APK: `gradle assembleDebug` (JDK 17 + Android SDK) lub workflow GitHub Actions „Build APK” → artefakt `app-debug.apk`.
